
# Simple To-Do List

## Description
Simple web application for managing daily tasks.

## Technologies
- HTML
- CSS
- JavaScript
- Git
- GitHub

## Features
- Add a task
- Delete a task
- Mark a task as completed
- Save tasks using localStorage

## Team
- Member 1: HTML and JavaScript
- Member 2: CSS and documentation

## Installation
1. Clone the repository.
2. Open the project folder.
3. Open index.html in your browser.
